# Random Password Generator

**Автор:** Виктория Забильская

## Описание программы


Это GUI-приложение для генерации случайных паролей с настраиваемыми параметрами. Проект разработан в рамках итоговой аттестации по курсу разработки GUI-приложений. Приложение позволяет пользователю:

настраивать длину пароля (от 6 до 32 символов) с помощью ползунка;
выбирать типы символов для включения в пароль (цифры, буквы, спецсимволы) с помощью чекбоксов;
генерировать пароль по нажатию кнопки;
просматривать историю сгенерированных паролей в таблице;
сохранять и загружать историю паролей в формате JSON.

## Функциональность
## Настройка длины пароля: ползунок позволяет выбрать длину пароля в диапазоне от 6 до 32 символов.
## Выбор символов: с помощью чекбоксов можно выбрать, какие символы будут использоваться в пароле:
цифры (0–9);
буквы (a–z, A–Z);
спецсимволы.
## Генерация пароля: при нажатии кнопки «Сгенерировать пароль» создаётся случайный пароль с выбранными параметрами.
## История паролей: все сгенерированные пароли сохраняются в таблице с указанием длины и времени создания.
## Сохранение и загрузка истории: история паролей сохраняется в файле password_history.json и автоматически загружается при запуске приложения.
## Инструкция по запуску
## Использование
Переместите ползунок, чтобы выбрать длину пароля (6–32 символа).
Отметьте чекбоксы для типов символов, которые хотите включить в пароль.
Нажмите кнопку «Сгенерировать пароль».
Сгенерированный пароль появится в поле вывода.
История всех сгенерированных паролей будет отображаться в таблице ниже.
## Тестирование
Приложение протестировано на следующих сценариях:
Позитивные кейсы: генерация паролей разной длины с различными комбинациями символов, сохранение и загрузка истории.
Негативные кейсы: попытка генерации пароля без выбранных символов (выдаётся сообщение об ошибке).
